Round-level, round-state, and enriched data

1 Setup

This report combines the dataset overview, round-level descriptive analysis, team/map/side comparisons, round-state analysis, and bomb/economy/player-state analyses into one logically ordered report. Summary tables appear in the rendered report. Figures are also saved as PDF files under ../reports/figures, relative to this QMD file.

Code 
library(tidyverse)
library(arrow)
library(knitr)
library(scales)

rounds_file <- "../data/analysis/rounds.parquet"
states_file <- "../data/analysis/round_states.parquet"
enriched_file <- "../data/analysis/round_states_enriched.parquet"
figures_dir <- "../reports/figures"
dir.create(figures_dir, showWarnings = FALSE, recursive = TRUE)

rounds <- read_parquet(rounds_file) |> as_tibble()
round_states <- read_parquet(states_file) |> as_tibble()

map_label <- function(x) tools::toTitleCase(sub("^de_", "", as.character(x)))

round_states_enriched <- round_states_enriched |> mutate(map = map_label(map))

  knitr::kable(x, digits = digits, format = "html")
}

  ggsave(file.path(figures_dir, filename), plot = plot,
         width = width, height = height, device = "pdf")
}

2 1. Dataset structure and quality

2.1 1.1 Overview of the datasets

rounds has one record per round; round_states has repeated snapshots over time within a round. round_states_enriched attaches selected round-level fields to every snapshot. It is a merged, deduplicated-by-column-selection analytical table: it keeps the snapshot rows and adds round context, making it useful for examining how round-level outcomes relate to the evolving state of a round. It is not one row per round.

Code 
dataset_overview <- tibble(
  dataset = c("rounds", "round_states", "round_states_enriched"),
  rows = c(nrow(rounds), nrow(round_states), nrow(round_states_enriched)),

Only columns that contain at least one missing value are shown. Missingness is not automatically an error: for example, planting-related fields are naturally unavailable in rounds where the bomb was not planted.

missing_by_dataset <- function(data, dataset_name) {
  tibble(
    dataset = dataset_name,
    column = names(data),
    missing_n = map_int(data, ~ sum(is.na(.x))),
    missing_pct = map_dbl(data, ~ 100 * mean(is.na(.x)))
  ) |>
    filter(missing_n > 0) |>
    arrange(desc(missing_n))
}

4.3 3.3 Round-end alive players and health

For each round, the round-end snapshot is the latest recorded snapshot at or before end_tick. Snapshots are periodic, so this is an approximation and may not equal the exact end tick.

Code 
round_end <- round_states_enriched |>
  filter(!is.na(end_tick), tick <= end_tick) |>
  group_by(match_id, map, round_num) |>
  slice_max(tick, n = 1, with_ties = FALSE) |>
  ungroup()

round_end_summary <- round_end |>
  group_by(map) |>
  summarise(
    rounds = n(),

5.1 4.1 Enriched data checks

The join should preserve the snapshot row count. Round-level fields repeat on every snapshot belonging to that round; therefore, missing values in fields copied from rounds are repeated across all snapshots for the affected round. This repetition is expected and explains why missing-cell counts can be much larger in the enriched table than in the one-row-per-round source.

6 5. Interpretation notes and limitations

  • rounds is the round-level source; round_states contains multiple snapshots per round; the enriched table combines them for analysis while retaining snapshot granularity.
  • Missing planting fields can be expected when no plant occurred. In the enriched data, any missing round-level value is repeated across every snapshot for that round, which can increase the missing-cell count.
  • Percentages in stacked charts are calculated within their stated grouping (usually within map); sample sizes should be considered when interpreting percentages.
  • Snapshot rows from the same round are not independent observations. Analyses intended to compare round outcomes should use one selected snapshot per round, as in the 30-second and round-end sections.
  • ct_win is the eventual round outcome repeated across snapshots; do not treat every snapshot as an independent outcome for predictive modelling. If building predictive models, split training and test data by match or round to avoid leakage.
  • Round-end and bomb timing analyses use periodic snapshots and therefore approximate the exact event times.
  • All figures are saved as PDFs in ../reports/figures.
